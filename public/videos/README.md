# Wedding Video Directory

Place your approved Picture Perfect Photography wedding video showreel here:

- **Required Filename**: `wedding-showreel.mp4`
- **Path**: `public/videos/wedding-showreel.mp4`
- **Format**: MP4 (H.264 / AAC) or WebM
- **Recommended Resolution**: 1920x1080 (1080p) or 2560x1440 (1440p)
- **Target Bitrate**: 2.5–5 Mbps (optimized for web streaming)
- **Audio**: Muted by default via HTML5 `<video>`
