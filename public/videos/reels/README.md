# Picture Perfect Photography — Wedding Reels Directory

Place your 9:16 vertical wedding reel video files in this folder:

- **Path**: `public/videos/reels/`
- **Aspect Ratio**: 9:16 Vertical (1080x1920 recommended)
- **Format**: MP4 (H.264 / AAC) or WebM
- **Target Bitrate**: 2.5–4 Mbps (optimized for fast web streaming)
- **Audio**: Muted autoplay by default per web standards; user unmutes on demand
